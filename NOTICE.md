# Local provenance notice

The Prompt/Context behavior, Dream Skin 1.5.11 theme validation helpers, and twelve personal wallpaper themes were recovered from this user's own disabled local backups dated 2026-08-25 and adapted for this cross-platform controller. The current wallpaper renderer is a new small static-CSS and blob-transfer implementation; the launcher, relay transaction, and cross-platform lifecycle code are new implementations.

The new code does not copy or install the old LaunchAgent/XDG watcher, AppKit menu app, hard-coded user paths, provider profiles, API keys, auth files, or persistent `launchctl setenv` behavior. Injection is an explicit one-shot launch and leaves no controller process running.

The `vendor/` renderer adapters are version-sensitive experimental integration code. They are not an official OpenAI extension API and must be re-verified after Desktop updates.
